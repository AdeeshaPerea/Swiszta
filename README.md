# SWISZTA - Hotel & Hospitality Services Web Application

![React](https://img.shields.io/badge/React-18.x-blue.svg)
![Vite](https://img.shields.io/badge/Vite-6.x-646CFF.svg)
![License](https://img.shields.io/badge/License-MIT-green.svg)

An integrated, pixel-perfect web application built for **SWISZTA Hotel & Hospitality Services**, Australia's premier hotel management and facility operations provider.

---

## 🌟 Key Features

- **Hero Slider & Ambiance Showcase**: High-resolution hotel lobby visual slider with dark glassmorphism overlay card and dynamic call-to-actions.
- **Floating Service Bar**: Instant access to core hospitality service lines (*Housekeeping, Laundry Services, Catering & F&B, Maintenance, Concierge, Procurement*).
- **Interactive Service Detail Modals**: Deep-dive operational breakdowns and feature highlights for every service line.
- **Custom Proposal Generator**: Interactive multi-step form for clients to specify property type, room count, required services, and contact info.
- **Client & Partner Carousel**: Interactive showcase featuring top hospitality brands (*Wyndham, Accor, IHG, Hilton, Marriott, Hyatt*) with full portfolio filtering.
- **Operational Video Showcase**: Embedded operational video player modal demonstrating staff training and service delivery standards.
- **Multi-Page Section Navigation**: Dedicated routing views for *About Us, Services, Solutions, Our Clients, Careers, and Contact Us*.
- **Responsive & Accessible Design**: Seamless layout adapted across desktop, tablet, and mobile displays with accessible navigation drawer.

---

## 🛠️ Tech Stack

- **Framework**: [React 18](https://react.dev/)
- **Build Tool**: [Vite](https://vitejs.dev/)
- **Icons**: [Lucide React](https://lucide.dev/)
- **Styling**: Vanilla CSS custom properties & modern design tokens (`Outfit` & `Inter` Google Fonts)
- **Deployment Ready**: Standard SPA configuration compatible with Vercel, Netlify, or GitHub Pages.

## 🚀 Getting Started

### Prerequisites

Ensure you have [Node.js](https://nodejs.org/) (v18.0 or higher) installed.

### Installation

1. Clone the repository:
   ```bash
   git clone https://github.com/YOUR_USERNAME/swiszta-hospitality.git
   cd swiszta-hospitality
   ```

2. Install dependencies:
   ```bash
   npm install
   ```

3. Start the development server:
   ```bash
   npm run dev
   ```

4. Build for production:
   ```bash
   npm run build
   ```
